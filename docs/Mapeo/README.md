# Mapeo de Casos de Prueba

Este directorio contiene la documentación y trazabilidad de los casos de prueba funcionales, de seguridad y automatización para el sistema UrbanBlade (barbería).

## Estructura de Archivos

- **bloque_1.md**: Casos de prueba de autenticación y acceso (IDs AUTH-001 a AUTH-020).
- **bloque_2.md**: Casos de prueba de gestión de usuarios (IDs USER-011 a USER-020).
- **bloque_3.md**: Casos de prueba de citas y agenda (IDs APPT-011 a APPT-020).
- **bloque_4.md**: Casos de prueba de pagos, inventario y panel administrativo (IDs PAY-011 a ADMIN-010).
- **bloque_5.md**: Casos de prueba de API, frontend/UI y pruebas complementarias (IDs ADMIN-011 a UI-010).
- **matriz_global.md**: Matriz de cobertura, trazabilidad y recomendaciones DevSecOps.
- **modelo_pruebas.md**: Modelo integral de pruebas, metodología, criterios y alcance.

## Numeración y Formato

Cada caso de prueba está identificado por un número de serie y un ID único, siguiendo el formato:

    | # / ID | Nombre de la Prueba | ... |

Ejemplo: `1 / AUTH-001`, `51 / USER-011`, etc.

## Total de Casos de Prueba

Actualmente documentados: **230** casos de prueba.

## Uso

- Revisar los archivos por bloque temático para consultar los casos de prueba.
- Utilizar la matriz global para visualizar la cobertura y trazabilidad.
- Consultar el modelo de pruebas para entender la metodología aplicada.
