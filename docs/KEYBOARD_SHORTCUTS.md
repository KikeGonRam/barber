# ⌨️ Keyboard Shortcuts Reference

## Navegación Principal

| Atajo | Acción | Descripción |
|-------|--------|-------------|
| `Ctrl+1` | Dashboard | Ir al dashboard principal |
| `Ctrl+2` | Barberos | Ir a gestión de barberos |
| `Ctrl+3` | Clientes | Ir a gestión de clientes |
| `Ctrl+4` | Inventario | Ir a gestión de inventario |
| `Ctrl+5` | Reportes | Ir a generador de reportes |
| `←` `→` | Tab anterior/siguiente | Navegar entre pestañas |
| `Escape` | Atrás | Volver atrás (en modal/submenu) |

## Edición & Formularios

| Atajo | Acción | Descripción |
|-------|--------|-------------|
| `Ctrl+S` | Guardar | Guardar formulario o cambios |
| `Escape` | Cancelar | Cancelar edición y cerrar modal |
| `Ctrl+L` | Limpiar | Limpiar campos del formulario |
| `Tab` | Siguiente campo | Ir al siguiente campo |
| `Shift+Tab` | Campo anterior | Ir al campo anterior |
| `Enter` | Enviar | Enviar formulario (en form) |

## Búsqueda & Filtros

| Atajo | Acción | Descripción |
|-------|--------|-------------|
| `Ctrl+K` | Buscar | Abrir búsqueda rápida (Cmd+K en Mac) |
| `Ctrl+F` | Buscar en página | Buscar dentro de la página actual |
| `Ctrl+Alt+L` | Limpiar filtros | Resetear todos los filtros |
| `Escape` | Cerrar búsqueda | Cerrar modal de búsqueda |

## Interfaz & Tema

| Atajo | Acción | Descripción |
|-------|--------|-------------|
| `Ctrl+Shift+D` | Toggle Dark Mode | Alternar modo oscuro/claro |
| `Ctrl+?` | Mostrar Ayuda | Mostrar este modal de atajos |
| `F5` | Refrescar | Actualizar página completa |
| `Ctrl+0` | Reset Zoom | Resetear zoom a 100% |
| `Ctrl++` | Zoom In | Aumentar zoom |
| `Ctrl+-` | Zoom Out | Disminuir zoom |

## Operaciones de Datos

| Atajo | Acción | Descripción |
|-------|--------|-------------|
| `Ctrl+N` | Nuevo | Crear nuevo elemento |
| `Ctrl+E` | Editar | Editar elemento seleccionado |
| `Delete` | Eliminar | Eliminar elemento seleccionado |
| `Ctrl+D` | Duplicar | Duplicar elemento seleccionado |
| `Ctrl+C` | Copiar | Copiar información |
| `Ctrl+V` | Pegar | Pegar información |
| `Ctrl+X` | Cortar | Cortar información |

## Tablas & Listas

| Atajo | Acción | Descripción |
|-------|--------|-------------|
| `↑` `↓` | Navegar filas | Moverse arriba/abajo en tabla |
| `Space` | Seleccionar fila | Seleccionar/deseleccionar fila |
| `Shift+Click` | Rango de selección | Seleccionar rango de filas |
| `Ctrl+A` | Seleccionar todo | Seleccionar todas las filas |

## Reportes & Exportación

| Atajo | Acción | Descripción |
|-------|--------|-------------|
| `Ctrl+P` | Imprimir | Imprimir página o reporte |
| `Ctrl+Shift+E` | Exportar | Abrir opciones de exportación |
| `Ctrl+Shift+S` | Guardar como | Guardar reporte con nuevo nombre |

## Acciones de Confirmación

| Atajo | Acción | Descripción |
|-------|--------|-------------|
| `Enter` o `Y` | Aceptar | Confirmar acción en diálogo |
| `Escape` o `N` | Rechazar | Cancelar acción en diálogo |
| `Ctrl+Shift+Del` | Eliminar permanente | Eliminar sin confirmación (⚠️) |

## Tips & Trucos

### 💡 Para Usuarios

1. **Busqueda rápida**: Presiona `Ctrl+K` en cualquier momento para buscar
2. **Dark Mode**: `Ctrl+Shift+D` es más rápido que hacer click
3. **Ayuda**: Si olvidas un atajo, presiona `Ctrl+?`
4. **Zoom**: Usa `Ctrl++/-` para aumentar/disminuir zoom si el texto es pequeño
5. **Sin ratón**: Navegación completa es posible solo con teclado

### ⚡ Para Power Users

1. **Búsqueda + Enter**: `Ctrl+K` + escribir + `Enter` = crear nuevo
2. **Tab entre campos**: Mantén `Tab` presionado para navegar rápido
3. **Shift+Tab**: Ir hacia atrás en formularios
4. **Ctrl+A + Delete**: Seleccionar todo y eliminar rápido
5. **Atajos Mac**: Usa `Cmd` en lugar de `Ctrl`

### 🔧 Personalización Futura

Los atajos pueden ser personalizables en **Preferencias** (próxima fase):
- Reasignar atajos según preferencia
- Crear atajos personalizados
- Exportar/importar configuración de atajos
- Perfiles de atajos (Power User, Casual User, etc.)

## Compatibilidad

### Windows/Linux
- Use `Ctrl` para la mayoría de atajos
- Some applications may use `Alt` instead

### Mac
- Use `Cmd` en lugar de `Ctrl`
- Example: `Cmd+K` para buscar, `Cmd+S` para guardar
- `Option` en lugar de `Alt`

### Mobile & Tablets
- Los atajos de teclado no están disponibles
- Usar interfaz táctil en su lugar
- Los modales se abren con botones en lugar de atajos

---

## Reportar Problemas

Si un atajo no funciona:
1. Verifica que no estés escribiendo en un input
2. Asegúrate de soltar las teclas rápidamente
3. Intenta en diferente navegador
4. Abre consola (F12) para ver errores
